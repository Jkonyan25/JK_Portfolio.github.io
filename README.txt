John Konyan — Portfolio
https://jkonyan25.github.io/JK_Portfolio.github.io/

A hand-built single-page portfolio deployed with GitHub Pages.

Structure
	index.html                  The whole page (hero, about, experience, skills,
	                            projects, education, contact).
	assets/css/portfolio.css    Design system: tokens, layout, components,
	                            light/dark themes, responsive rules.
	assets/js/portfolio.js      Theme switching, navigation, scroll reveals,
	                            animated stats, progress bar, back-to-top.
	assets/js/contact.js        Contact form submission via EmailJS.
	assets/Konyan_John_Resume.pdf   Résumé linked from the nav and contact section.
	images/                     Portrait and project imagery (web-optimized).

Notes
	- Appearance follows the system light/dark setting and remembers a manual
	  choice in localStorage.
	- All motion is disabled automatically for visitors who have "reduce motion"
	  enabled, and every section stays readable with JavaScript turned off.
	- The files from the original HTML5 UP "Dimension" template (assets/sass,
	  assets/css/main.css, assets/js/main.js and friends) are kept for reference
	  but are no longer loaded by the page.
